## Key Learnings

- Calibre is an offline library manager, not a media player
- Virtual libraries are filters, not true separation
- Flatpak resolves most Linux dependency and Qt conflicts
- GPU acceleration is a major cause of segmentation faults
- Single-file audiobooks are stable; multi-file audio is not
- Tags are more scalable than splitting into many libraries
- File system organization alone becomes unmanageable at scale
- Physical library separation is the most reliable structure
