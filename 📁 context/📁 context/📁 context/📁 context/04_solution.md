## Final Working State

- Calibre runs via Flatpak for isolation
- Each content type uses a separate physical library
- Podcasts stored in /home/op/podcast
- Audiobooks stored separately
- Tags used for subcategories instead of splitting libraries further
- GPU acceleration disabled for stability
- Qt theme forced to Fusion for consistency

## Result

Stable, offline-first library system with:
- No crashes during metadata editing
- Clean separation of content types
- Fast switching between libraries
- Reduced filesystem clutter
